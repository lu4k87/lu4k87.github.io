### 🤖 Projekt 1: UX Robot

> **„Der Mensch führt. Die KI assistiert.“**

Forschungs- und Evaluierungsplattform für multimodale Teleoperation des UFactory xArm Lite 6 auf ROS 2 Humble. Steuerung über Web-UIs, 6-DoF WebXR (Meta Quest 3), Blicksteuerung (Tobii Pro Glasses 3), Sprachbefehle (Whisper), Gamepad und KI-Assistenz (VLA-M Agent). 

- **Projekt-URL:** [lu4k87.github.io/p_1](https://lu4k87.github.io/p_1)
