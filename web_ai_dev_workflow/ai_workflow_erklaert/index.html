Synchronizer

Nur eigene, geprüfte Dateien – nie --force

Doku nachziehen, Commit durch den pre-commit-Hook, Push. Danach ist der Claim gelöscht und die Dateien sind wieder frei.

  • $ git commit -m "feat(docs): light/dark toggle on project page"
  • $ git push → origin main 4f2c9e1

Warum so? Das Datei-Register kennt jede Datei – fremde Änderungen landen nie im eigenen Commit. Ohne --force bleibt Git die eine Quelle für Laptop, Labor und Home-PC.
