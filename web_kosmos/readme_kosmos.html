Kosmos
Reise durch das All

Eine interaktive 3D-Reise in 31 Stationen, 13 davon auf der Reiseroute: von der ISS über Erde und Mond bis zum beobachtbaren Universum. Ein Klick auf ein blaue Markierung fliegt in die nächste Ebene, „Hinaus“ zoomt in die größere zurück.

Jede Zahl der Seite hat eine Quelle (NASA, JPL, ESA, Fachartikel); was ein Modell oder eine eigene Rechnung ist, steht dabei.

  • 31 Stationen, 13 auf der Route, ein durchgehender Flug
  • Echte Bahnen (JPL) und Sternkatalog (Yale BSC)
  • Schalter und Regler je Station
  • Kein Build, läuft lokal im Browser

So bedienst du es

  1. Schauen

    Ziehen dreht die Ansicht, Scrollen zoomt. Am Zoom-Anschlag weiterscrollen fliegt hinaus bzw. hinein.

  2. Hineinfliegen

    Eine blaue Markierung führt eine Ebene tiefer, z. B. von der Milchstraße in den Orion-Nebel. Der Flug ist durchgehend, ohne Schnitt.

  3. Entdecken

    Weiße Markierungen schwenken die Kamera hin und öffnen die Info-Karte. Die Infotafel nennt Kennzahlen, Schalter und Quellen.

  4. Hinausfliegen

    „Hinaus“ zoomt in die größere Station. Der Stationsbaum links springt direkt zu jeder Station.

Die Oberfläche

Die Szene füllt das ganze Fenster. Alles Bedienende liegt als Schicht darüber und lässt sich ausblenden.

Die Stationen

Die Stationen bilden einen Baum: „Hinein“ führt zu einem Kind, „Hinaus“ zur Elternstation. Knoten mit mehreren Zielen sind Erde, Sonnensystem, Jupiter, Saturn, Mars und Milchstraße.

Starten

Die Web-App ist noch in Arbeit und nicht online. Diese Seite beschreibt den aktuellen Stand; die Bilder kommen, sobald die Oberfläche fertig ist.
git clone https://github.com/lu4k87/__project_kosmos.git
cd __project_kosmos
npm run serve        # http://localhost:8480/

Voraussetzung ist ein Browser mit WebGL 2 und Python 3 für den lokalen Server (ohne npm: python3 -m http.server 8480 --directory web). three.js liegt im Projekt (web/vendor/), ein Build ist nicht nötig.
