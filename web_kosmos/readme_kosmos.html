3D-Web-App · three.js · WebGL 2

Kosmos
Reise durch das All

Eine interaktive 3D-Reise in zehn Stationen: von der Erde mit ihrem Mond bis zum beobachtbaren Universum. Ein Klick auf ein blaues Abzeichen fliegt in die nächste Ebene, „Hinaus“ zoomt in die größere zurück.

Jede Zahl der Seite hat eine Quelle (NASA, JPL, ESA, Fachartikel); was ein Modell oder eine eigene Rechnung ist, steht dabei.

  • 10 Stationen, ein durchgehender Flug
  • Echte Bahnen (JPL) und Sternkatalog (Yale BSC)
  • Schalter und Regler je Station
  • Kein Build, läuft offline im Browser

So bedienst du es

  1. Schauen

    Ziehen dreht die Ansicht, Scrollen zoomt. Am Zoom-Anschlag weiterscrollen fliegt hinaus bzw. hinein.

  2. Hineinfliegen

    Ein blaues Abzeichen führt eine Ebene tiefer, z. B. von der Milchstraße in den Orion-Nebel. Der Flug ist durchgehend, ohne Schnitt.

  3. Entdecken

    Weiße Abzeichen schwenken die Kamera hin und öffnen die Info-Karte. Die Infotafel nennt Kennzahlen, Schalter und Quellen.

  4. Hinausfliegen

    „Hinaus“ zoomt in die größere Station. Der Stationsbaum links springt direkt zu jeder Station.

Die Oberfläche

Die Szene füllt das ganze Fenster. Alles Bedienende liegt als Schicht darüber und lässt sich ausblenden.

Die zehn Stationen

Die Stationen bilden einen Baum: „Hinein“ führt zu einem Kind, „Hinaus“ zum Eltern. Die Milchstraße ist der Knoten mit mehreren Zielen.

Starten

Die Web-App ist noch in Arbeit und nicht online. Diese Seite beschreibt den aktuellen Stand; die Bilder kommen, sobald die Oberfläche fertig ist.
git clone https://github.com/lu4k87/__project_kosmos.git
cd __project_kosmos
npm run serve        # http://localhost:8480/

Voraussetzung ist ein Browser mit WebGL 2. three.js liegt im Projekt (web/vendor/), ein Build ist nicht nötig.

AdresseWirkung
#station=sgraDirekt in eine Station springen (z. B. earth, solar, galaxy)
